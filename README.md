# SolarEngine


# What is this project?

This project is a large task for me to undertake. It is me wanting to make my own 3D game engine from *mostly* scratch.    

## The goals

I have taken courses in college for game engine design, but they were in the wretched Java programming language and I would like to expand my knowledge on C and C++.
I also have grown to not care for a lot of object oriented design principles and because of that, I would like to relearn how I program things that I know mostly how to do in a OOP way.

## Why *mostly*

Although I could go for a complete scratch and really expand my knowledge, as of right now I am planning on using GLFW for window creation, if that changes in the future I will make note of it here.

# Target platform *for now*
I am currently developing this on linux, specifically omarchy. *where my omarchy bros at?* so for now the target platform will be linux
- wanting to in the future add windows support, mac support will not be happening as I do not own a macbook and do not plan on buying one at this point.
